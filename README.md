## Как да добавяш съдържание (без да пипаш код)

Сайтът е направен така, че галерията, видеата и документите с класирания
да се обновяват **автоматично**, само като качиш файл в правилната папка тук,
в GitHub. Не е нужно да редактираш `index.html`, `styles.css` или `script.js`.

### 📸 Да добавиш снимка в галерията
1. Отвори папката [`images/gallery`](images/gallery) в този repository.
2. Натисни **Add file → Upload files**.
3. Провлачи снимката (.jpg / .png / .webp) и натисни **Commit changes**.
4. Готово — снимката ще се появи в галерията на сайта до няколко секунди.

### 🎥 Да добавиш видео
Същото, но в папката [`videos`](videos). Поддържат се `.mp4` файлове
(препоръчително — най-съвместими с всички браузъри). Опитай да качваш видеа
под 25 MB — по-леки видеа се зареждат по-бързо на телефон.

### 📄 Да добавиш PDF с класиране/протокол
Качи PDF файла в папката [`documents`](documents) — ще се появи автоматично
в раздел „Състезания“ под „Пълни протоколи“.

### 🏆 Да добавиш ново състезание в класацията (раздел "Състезания")
Отвори файла [`results.json`](results.json), натисни моливчето (Edit) горе
вдясно и добави нов запис **в началото на списъка** по следния образец:

```json
{
  "place": "5",
  "event": "Име на състезанието",
  "location": "Място",
  "dateLabel": "2026",
  "note": "По желание — кратка бележка.",
  "photo": "име-на-файл.jpg"
}
```

Ако искаш снимка до резултата, качи я в `images/results/` и посочи същото
име във `"photo"`. Полето `"photo"` е по избор — може да го пропуснеш.
Commit-ни промяната и новият резултат веднага ще се появи най-отгоре в
раздел „Състезания“.

## Технически детайли (за по-любопитните)

- Чист HTML/CSS/JS, без build стъпка — хоства се директно през **GitHub Pages**.
- Галерията, видеата и документите се зареждат в реално време през
  публичното [GitHub REST API](https://docs.github.com/en/rest/repos/contents)
  директно от браузъра на посетителя — затова качването на файл е достатъчно.
- Ако GitHub Pages не е "хванал" последната промяна веднага, изчакай 1-2 минути
  и презареди страницата (Ctrl/Cmd + Shift + R за твърдо презареждане).
